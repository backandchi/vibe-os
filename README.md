## 🌟 Nima uchun VibeOS?

**VibeOS** — dasturchilar, prompt injenerlari va sun'iy intellekt vositalari bilan maksimal tezlikda kod yozuvchilar uchun yaratilgan maxsus Linux distributividir.

1. **⚡ CachyOS Yadro Tezligi:** BORE/EEVDF scheduler va x86-64-v3/v4 optimizatsiyalari evaziga kod kompilyatsiyasi va ilovalar ochilishi sezilarli tezroq.
2. **🪟 Windows Qisqartmalari:** Yangi foydalanuvchilar qiynalmasligi uchun `Win+E` (Fayllar), `Win+V` (Clipboard tarixi), `Win+Shift+S` (Snipping tool), `Ctrl+Shift+Esc` (Task Manager) out-of-the-box ishlaydi.
3. **🤖 O'rnatilgan AI Muhiti:** `Ollama` mahalliy modellari va `Win + Space` orqali ochiluvchi qalqib chiquvchi AI Scratchpad.
4. **📖 Vibe Wiki:** Tizim ichida to'liq o'rnatilgan interaktiv qo'llanma (`Win + /` yoki terminalda `vibe-wiki`).
5. **🛠️ Eng Zamonaviy Dev Runtimes:** `uv` (o'ta tez Python), `bun` (JS/TS), `rustup`, `lazygit`, `lazydocker`, `neovim`, `kitty`, `fastfetch`.

## ⌨️ Asosiy Qisqartmalar (Cheatsheet)

### 🪟 Windows Tizimidan Moslashgan:
- **`Win + E`** — Fayllar boshqaruvi (File Manager)
- **`Win + V`** — Nusxa olish tarixi (Clipboard History)
- **`Win + Shift + S`** — Ekran qismini rasmga olish (Snipping Tool)
- **`Ctrl + Shift + Esc`** — Vazifalar boshqaruvi (Task Manager / btop)
- **`Win + R`** — Dasturlar qidiruvi va ishga tushirish (Run Launcher)
- **`Win + D`** — Ish stolini ko'rsatish
- **`Win + L`** — Ekranni qulflash

### ⚡ Vibe Coding:
- **`Win + Space`** — **Floating AI Scratchpad** (Tezkor AI yordamchi)
- **`Win + /` yoki `Win + F1`** — **Vibe Wiki** (Barcha buyruqlar va qo'llanma)
- **`Win + Enter`** — GPU-tezlatilgan Kitty terminali
- **`Win + C`** — Kod muharriri (VS Code / Cursor / Neovim)
- **`Win + G`** — Lazygit (Terminal Git boshqaruvi)
- **`Win + M`** — Lazydocker (Konteynerlar boshqaruvi)

## 🚀 ISO Obrazini Yig'ish (GitHub Actions orqali)

Ushbu distributivni o'z kompyuteringiz quvvatini sarflamasdan, to'g'ridan-to'g'ri GitHub Actions bulutida yig'ishingiz mumkin:

1. Ushbu ombordagi **[Actions](https://github.com/backandchi/vibe-os/actions)** bo'limiga o'ting.
2. Chap tomondan **"VibeOS Build ISO"** ni tanlang.
3. O'ng tomondagi **"Run workflow"** tugmasini bosing.
4. Taxminan 15-25 daqiqadan so'ng tayyor yuklanuvchi `.iso` fayl **[Releases](https://github.com/backandchi/vibe-os/releases)** bo'limida va Artifacts'da paydo bo'ladi!
